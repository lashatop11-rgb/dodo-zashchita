# Сценарий защиты «Додо Пиццы»

Текст выступления для защиты семестровой работы «Анализ бизнес-процессов „Додо Пиццы“» (группа ММ 1-1).

| № | Спикер | Слайды | Тема |
|---|---|---|---|
| 1 | Алексей Слепцов | 1–5 | Вступление и описание компании |
| 2 | Даниил Рубаненко | 6–9 | Цепочка ценностей Портера |
| 3 | Владислав Дмитриев | 10–11 | Процесс «Приготовление заказа» |
| 4 | Лев Ненашев | 12–14 | IDEF0 и заключение |

На странице:

- текст каждого спикера по слайдам, с подсказками, что показать на экране, и фразами передачи слова;
- кнопки 1–4: оставляют на странице только текст одного спикера (ссылки вида `#speaker-2`);
- вероятные вопросы комиссии с короткими ответами;
- секундомер для прогона, крупный текст и режим «не гасить экран».

## Как устроено

Один статический файл `index.html` без сборки. Сайт размещён на Vercel и обновляется сам после каждого push в ветку `main`.

Чтобы поправить текст, отредактируйте `index.html` и запушьте изменения.
